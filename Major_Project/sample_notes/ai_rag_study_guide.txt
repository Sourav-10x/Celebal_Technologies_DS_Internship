High-Performance Retrieval-Augmented Generation (RAG) Study Notes

#1. Introduction to RAG

Retrieval-Augmented Generation (RAG) is an architectural framework that enhances Large Language Models (LLMs) by grounding them with external data. Standard LLMs suffer from knowledge cutoffs and hallucinations. RAG solves this problem by fetching relevant documents from a vector database before synthesizing an answer.

2. Text Chunking Strategies

Text chunking is the process of breaking large documents into smaller, manageable text segments. 
- Fixed-size chunking: Splits text into uniform character or token lengths (e.g., 500 characters with 100 character overlap).
- Semantic chunking: Uses structural boundaries like paragraphs, headings, or sentence boundaries to preserve contextual context.
- Overlapping windows ensure that critical sentences split across chunk boundaries are not lost during similarity search.

3. Vector Embeddings and Vector Databases
A vector embedding is a high-dimensional numerical representation of text where semantically similar phrases are located close to each other in vector space.
- Cosine Similarity: Measures the cosine of the angle between two multi-dimensional vectors. A cosine score of 1.0 indicates identical directional meaning.
- Indexing: Popular vector stores include FAISS, ChromaDB, and Pinecone. They allow nearest-neighbor queries in milliseconds across millions of vectors.

4. Synthesis & Grounding
When a user submits a prompt, the system:
1. Converts the user query into a query embedding.
2. Performs a top-k cosine similarity search to retrieve relevant text chunks.
3. Injects retrieved chunks into the system prompt as context.
4. Generates an accurate, cited response with zero hallucination.

5. Flashcard Summary Definitions
- Retrieval-Augmented Generation: An AI technique combining vector document search with generative language models for grounded QA.
- Vector Embedding: A dense numeric matrix representing words or documents in semantic vector space.
- Cosine Similarity: A mathematical metric computing the angle between two vectors to determine semantic similarity.
- Text Chunking: Segmenting continuous text into contextual blocks for optimal vector search.
